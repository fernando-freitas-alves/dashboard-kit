# Dashboard Kit for React

Private MIT release candidate. Install the local tarball produced by `npm pack`.

```tsx
import { Dashboard, createHttpAdapter } from "@loadsmart/dashboard-kit";
import "@loadsmart/dashboard-kit/styles.css";
```

Use a stable options object with a namespace and an authenticated adapter. See the repository demo and security guide for a complete integration. Server imports are safe; mount the interactive dashboard on the client.
