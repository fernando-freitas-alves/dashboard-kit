Your dashboard. Your application.

Dashboard Kit handles the board and chart UI. Your adapter controls data, persistence and access.

import { Dashboard, createHttpAdapter } from '@loadsmart/dashboard-kit';
import '@loadsmart/dashboard-kit/styles.css';

const options = {
  namespace: 'sales:v1:current-user',
  adapter: createHttpAdapter('/api/dashboards', {
    headers: () => ({ 'X-CSRF-Token': csrfToken })
  }),
};

<Dashboard options={options} />

Connect your backend

Implement the DashboardAdapter interface, or use the Python service with your own scope resolver and data adapter. Query validation, user permissions, authentication and CSRF are host responsibilities.

Style it

Override dashboard CSS variables. Supply your own palette, toolbar, chart editor, table columns and chart renderers through options. Keep the options object stable between renders.

Try AI

Copy demo/.env.example to demo/.env and set OPENAI_API_KEY. The key stays server-side. Set OPENAI_MODEL and OPENAI_REASONING_EFFORT for a model available to your account. Restart the demo.

Before hosting

This sample is a local, single-user playground with synthetic data. Replace its local identity and origin policy with your application's authentication and authorization. Add production storage, CSRF protection, request limits, AI budgets and a sharing policy.
