# Source and media

Dashboard Kit originated in Loadsmart Labs. This repository contains a standalone source snapshot. It excludes the Labs Git history, application code, internal recordings, employee data, and credentials. Package names retain the Loadsmart namespace. The runtime does not require a Loadsmart service.

The library uses MIT with its copyright attribution retained. Bundled dependencies keep their own licenses. See [third-party notices](../THIRD_PARTY_NOTICES.md).

The demo uses fictional sales data. Its screenshots contain no employee or customer information.

The public video contains original demo scenes and a synthesized soundtrack created for this project. It excludes the opening from the private template-based preview. No third-party template source or reference clip is included in this repository. The video uses Inter, which is available under the [SIL Open Font License](https://github.com/rsms/inter/blob/master/LICENSE.txt). No font file is distributed here.
